# Changelog

## [0.0.1] - 2026-04-10

### Added

- Inline autocomplete with `[[` trigger for note linking
- Quick note creation with Ctrl+N shortcut
- Smart note search with ranking (exact, prefix, contains)
- Native Zotero `zotero://note/` links with note titles
- Quick Note collection for auto-organization
- VSCode-style popup UI with keyboard navigation
- Debounced search input filtering
- Note link autocomplete orchestrator with cache management
